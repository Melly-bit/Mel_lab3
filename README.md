# Temperature converter
## Description
A simple C++ console program that calculates a the user input into which temperature they are looking for. You pick you preferred temperature between with three options being celsius, kelvin, or fahrenheit.
## How to Run
1. Open the project folder in Visual Studio.
2. Press Ctrl+F5 to build and run.
3. Chose a case 1-3 of what temperature you would like to convert the current temperature too.
4. Input a number into the progarm and you'll have a result
## Sample Input / Output
Input: 32 for celsius
Output: 89.6 for Fahrenheit
